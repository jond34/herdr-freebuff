# herdr-freebuff Agent Rules

- This is a standalone public repository. Keep it usable without any private
  workspace repo, path, manifest, or generated file.
- Treat all tracked content as public: synthetic fixtures only. Never commit
  real Freebuff chat logs, prompts, local paths, credentials, or personal data.
- Linux-first. The v1 target is Herdr 0.9.2+ with Freebuff 0.2.x in the same
  Linux/WSL2 distro; Windows-native Herdr driving WSL Freebuff is unsupported.
- Do not replace `~/.local/bin/freebuff` or install a global PATH wrapper.
