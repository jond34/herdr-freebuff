# herdr-freebuff Agent Rules

- House rules: `~/repos/AGENTS.md` (source: `agent-kit/AGENTS.shared.md`).
- Privacy label: `public-github`; this is the explicit owner-approved exception.
  Keep tracked files public-safe: synthetic fixtures only, never real chat logs,
  prompts, local paths, credentials, or personal data.
- Linux-first. The v1 target is Herdr 0.9.2+ with Freebuff 0.2.x in the same
  Linux/WSL2 distro; Windows-native Herdr driving WSL Freebuff is unsupported.
- Do not replace `~/.local/bin/freebuff` or install a global PATH wrapper.
