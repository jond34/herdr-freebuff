## Why this is not a GitHub fork

The Herdr marketplace excludes forks. This repository was created standalone
and seeded from a clone of TheMetalStorm's repository so the original history
is preserved without a fork relationship. That keeps the marketplace eligible
while attribution stays in the commits, this file, and the README lineage.
